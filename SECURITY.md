# Security Policy

This repository currently contains design documentation and no deployable implementation.

Do not commit tenant IDs, client IDs, client secrets, private keys, access tokens, real mailbox addresses, form submissions, customer data, or production configuration. Use placeholders in documentation and secret-management facilities in implementation repositories.

Security issues should be reported privately to the repository owner through the security-reporting channel configured on GitHub. Do not include live credentials or personal data in an issue.
